# 🛒 Instamart Analytics Dashboard

An interactive Power BI dashboard analyzing sales performance, order categories, customer purchasing behavior, and delivery insights for Instamart.

---

## 📌 Project Overview
This repository contains a complete Power BI Report file (`.pbix`) designed to evaluate quick-commerce operational metrics and product sales trends.

* **Format:** Power BI Report (`.pbix`)
* **Tool Used:** Microsoft Power BI Desktop

---

## 📁 Repository Structure
* `Instamart_Dashboard.pbix` - Complete Power BI report file containing data model, DAX measures, and interactive visuals.
* `README.md` - Documentation and project summary.

---

## 🛠️ Key Analysis & Features
* **Sales & Category Breakdown:** Product-wise sales performance and top-performing categories.
* **Order Dynamics:** Order patterns across peak delivery hours and days.
* **Customer Insights:** Repeat orders, basket size analysis, and spending patterns.

---

## 🚀 How to Run
1. Click the **`Code`** button above and select **Download ZIP**.
2. Ensure **Microsoft Power BI Desktop** is installed on your computer.
3. Open `Instamart_Dashboard.pbix` to interact with the dashboard.
